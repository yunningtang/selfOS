# 校准记录 / Calibration notes

所有判定阈值与权重都在代码里以具名常量暴露，可用下面的脚本复现。

## 1. 旺衰与格局（`scripts/calib-patterns.mts`）

按《三命通会》《子平真诠》《滴天髓》对格局的定义构造的 15 个典型命造（曲直、炎上、稼穑、从革、润下五专旺；从财、从儿、从杀；财多身弱印透不从；建禄得令得地；杀印相生；伤官配印；禄刃双根食伤生财；印重；官杀三透会火），每例给出预期的旺衰、特殊格与喜用。

- 基线模型 9/15 → 加入 三合/三会局、自坐禄刃 项并对权重做网格搜索（15552 组）后 14/15 → 修正「中和取用」规则（官杀已重时不再按身强取泄克）后 15/15。
- 采用的权重：日支 1.8（原 1.2）、休 0.95 / 囚 0.85 / 死 0.7（原 0.9 / 0.75 / 0.6）、自坐禄刃 +0.8、三合局 +1.2、半合（含中神）+0.5、三会 +1.4、身弱阈值 40%（原 45%）。
- 从格条件改为经典表述：日主无根、印比不透干（从儿格允许比劫）、日主占比 ≤12%、印 ≤14%。
- 专旺 / 从强需同党 ≥62% 且官杀 <8%。

## 2. 断语分层与去矛盾（`verdicts.ts`）

- 每条断语带 `tier`：core（格局与旺衰定性，约 11 条）、detail（十神宫位具体断语，约 52 条）、reference（纳音、藏干余气、神煞落柱等，约 32 条）。界面默认展开 core 与 detail，reference 折叠。
- 每条可带 `claim`（如 `dm=strong`、`wealth=weak`）；同一 key 不同值视为矛盾，只保留可信度高的一条。

## 3. 运势评级（`scripts/calib-dist.mts`）

150 张随机命盘 × 40 年：评级分布 吉（≥1）43%、平 20%、忌（≤−1）37%，大运分布相同量级，无系统性偏向。权重见 `forecast.ts` 的 `FORECAST_WEIGHTS`。真实事件回测脚本 `scripts/backtest.mts`，输入带年份结果的案例文件即可输出一致率与混淆表；目前没有标注数据，这一步留待积累。

## 4. 资产模型（`wealth.ts`）

- 未填现实背景的随机命盘：小康 48%、温饱 33%、中产 19%，中位落在全国家庭净资产中位附近。
- 分段（万元，全国口径）：<20 / 20–80 / 80–300 / 300–1000 / 1000–5000 / >5000；按城市系数缩放显示：一线 ×2.2、新一线 ×1.5、二线 ×1.2、三四线 ×0.85、县乡 ×0.5、海外发达 ×2.5。

## 5. 历表后端（`scripts/mit-vs-swiss.mts`）

MIT 后端（astronomy-engine）与 Swiss Ephemeris：太阳黄经差 ≤2.4″，均时差差 ≤0.012 分，节气时刻差 ≤1 分；400 张随机命盘四柱全部一致。

## 喜忌取用（2026-10 更新）

- 从强 / 专旺 多一道门槛：若食伤、财、官杀两干以上透出，且其总占比 ≥ 20%（`PATTERN_THRESHOLDS.dominantLeakMax`），不作从强，按扶抑取用并记「印比成党，食伤泄秀」。否则 辛生未月、壬癸双透 的命会被判成从强而「喜土金」，与《穷通宝鉴》壬甲淘洗疏土之旨相悖。
- 扶抑之上再调候：亥子丑、巳午未月出生，或日主中和者，调候首用之五行直接列为喜用（若该五行已占 ≥ 35% 则不加）。两法一致时标注「真用神」并排在最前。
- 通关：两个相克的五行各占 ≥ 22% 而其间的通关五行 < 10% 时，通关五行列为喜用。
- `analysis.effective.basis` / `notes` 记录取用依据，排盘页、摘要条与通俗解读均据此显示。15 个校准命盘仍为 15/15。
