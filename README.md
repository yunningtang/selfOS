## ⚡ 项目概述

**selfOS** 是一款探索个体「自性化」（Individuation）路径的深度仿真引擎。它旨在将碎片化的数字记忆、生命叙事与深层心理结构相结合，在 **卡巴拉生命之树** 的拓扑逻辑中构建出一个高保真的"内在心理剧场"。

系统通过将复杂的心理动力学参数化，驱动代表不同内在能量的智能体进行模拟博弈。其核心价值在于揭示潜意识中的涌现行为，帮助个体识别内在阻力并寻找动态平衡。

> **"理解'为什么'比知道'是什么'更有决策价值。"**

## 🔄 核心工作流：四世界流水线

selfOS 的运行逻辑遵循卡巴拉的"四世界"演化模型，将原始数据升华为觉察：

1. **神性界 (Atzilut - 意志)**：确立自性化核心意图，定义全局 Agent 的原始动力与偏好。
2. **创造界 (Beria - 结构)**：利用 **GraphRAG** 技术构建生命叙事图谱，自动提取核心信念簇与情感锚点。
3. **形成界 (Yetzirah - 演化)**：内在议会博弈阶段。代表限制、创造、阴影与观察者的智能体在模拟空间内进行多轮交互。
4. **物质界 (Assiya - 显现)**：输出多维分析报告，通过实时监测关键变量，反馈心理能量的流向。

## 🏗️ 技术架构

项目采用模块化设计，确保心理逻辑与计算架构的高度解耦：

| 层级 | 模块 | 说明 |
|------|------|------|
| **感知层** | Perception Engine | 全域数字记忆提取，将非结构化文本转化为结构化心理图谱 |
| **认知层** | Agent Council | 基于原型的智能体实例化（防御者、创造者、调停者） |
| **认知层** | Long-term Memory | 跨时间维度的认知追踪与模式识别 |
| **逻辑层** | Dynamic Topology Router | 基于生命之树 22 条路径的能量通信协议 |
| **逻辑层** | Parametric Model | 高精度参数作为智能体决策权重的底层变量 |
| **表现层** | Visualization Interface | 动态展示心灵能量在各原质（Sephiroth）间的张力 |

## 🌑 系统深度逻辑：阴影检测与自性整合

selfOS 的独特之处在于对"非平衡状态"的监测。通过引入**阴影探测模块**，系统能够捕捉被压抑或忽视的情绪簇：

- **路径监测**：实时分析 22 条路径的流量分配，识别能量滞留点。
- **变量分析**：引入 $Grip$（抓取度）与 $Resistance$（抗拒度）作为动态参数，量化心理执着程度。
- **自性化反馈**：通过模拟释放变量后的系统涌现结果，引导用户探索潜在的整合路径。
